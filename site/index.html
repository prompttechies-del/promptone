Ask questions with answers you can use.

Send a state and a few typed questions. PromptOne answers all of them in one pass and returns structured results your code can branch on directly.

You send

{
  "state": {"body": "I was charged twice."},
  "questions": {
    "department": {"type": "choice",
      "criteria": {"billing": "payments",
                   "technical": "bugs"}},
    "urgency": {"type": "score",
      "criteria": {"0": "low", "2": "critical"}},
    "refund": {"type": "noul"}
  }
}

You get back

{
  "department": {"choice": "billing",
    "probabilities": {"billing": 0.94, "technical": 0.06}},
  "urgency":    {"score": 1.84},
  "refund":     {"probability": 0.91}
}

Choice

Pick one option from a list you define, with a probability for every option. department → billing

Score

Place the input on an ordered scale such as urgency, severity or frustration. urgency → 1.84 of 2

Probability

How likely a statement is true, ready for your own thresholds. refund requested → 0.91

Running in three steps.

Everything runs on your own machine. The playground comes with the server.

  1. Install the package and the server

    pip install "promptone[serve]"

  2. Start the server

    promptone-serve

  3. Ask from code, or open the playground at localhost:8000/ui

    from promptone import Router router = Router(preload=True) result = router.predict( {"body": "I was charged twice."}, {"refund": {"type": "noul", "instructions": "Is a refund requested?"}}, ) print(result["answers"]["refund"])

Stop waiting for tokens.
